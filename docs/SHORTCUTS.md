# Keyboard and mouse

| Shortcut | Action |
|---|---|
| V / B / H | Select and move / draw box / pan the canvas |
| N | Start a new object track; one per identity |
| I | Change/reuse track ID, reassign the selected class, or choose its color |
| 1 / 2 | Select the first / second named class |
| Tab | Cycle all classes while the canvas has focus |
| [ / ] | Previous / next keyframe for the selected track and class |
| F / D | Next / previous exact source frame |
| Shift+F / Shift+D | Forward / back ten frames |
| Enter | Next frame; edits save automatically |
| C | Copy the previous frame’s selected-class box |
| K | Fill between drawn/corrected boxes of the selected class |
| Delete | Delete the selected-class box on this frame |
| Shift+Delete | Delete the selected class over a frame range |
| Ctrl+Z / Ctrl+Shift+Z | Undo / redo, including generated boxes |
| Ctrl+S | Save explicitly |
| Escape | Cancel a gesture or close a dialog |
| Space | Tap to play/pause; hold and drag to pan |
| 0 | Fit the image |
| ? | Search actions and remap shortcuts |

Drag to draw a missing box. Drag inside the selected box to move it; drag an edge or corner to resize. **Alt+drag** replaces a box. Scroll to zoom around the cursor. Correcting an interpolated box makes it an anchor for that class.

**Copy to class…** copies the selected class across the whole track. **Restore range** repairs a deleted interval. These actions have buttons rather than additional default shortcuts.

Frame navigation during a drag commits to the starting frame first. Shortcuts are ignored in text fields and dialogs; repeated destructive keys are ignored. Tab keeps normal keyboard navigation outside the canvas. Remapped keys are saved in your browser.

No individual approval step is required. Review and structural validation happen under **Finish**. Ghost-frame overlays have been removed. Class eyes and track eyes/focus affect only display; all saved boxes appear in review and export.
