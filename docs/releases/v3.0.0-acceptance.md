# Version 3.0.0 verification

Executed on 23 September 2026 during release preparation:

| Check | Result |
|---|---|
| Backend domain/API/update/packaging tests | 124 passed |
| Frontend domain and geometry tests | 81 passed in 15 files |
| Chrome browser acceptance | Full 31-test suite passed; after two late fixes, all 8 affected/new cases passed (33 unique scenarios overall) |
| TypeScript and production build | Passed; Vite reports a non-blocking bundle-size advisory |
| Manual computer-use test | Drew a box, opened its context menu, copied into another class on the same ID, zoomed, panned, and fitted the image |
| Existing project preservation | Schema checks passed; project/video/frame/entity/operation content hashes were identical before and after the 3.0.0 service restart |

Browser tests use isolated synthetic videos and a separate database. They cover three named classes on one identity, independent interpolation, deletion/recovery, exact undo, save/reload, visibility persistence, JSON v3, review/validation/export, canvas tools/context menus, and updater recovery. Updater browser tests mock release responses; backend tests verify release parsing, checksum/size checks, trusted asset URLs, and handoff behavior separately.

The Debian prototype passed installation, startup, restart, exact frame decode, multi-class annotation, review/validation/export, reinstall, and removal checks in a disposable Debian container. Final installer reports are distributed alongside the actual release assets; use those reports for the packaged version's environment and result. Windows testing under Wine is not native Windows 11 desktop validation. The release workflow adds a Windows CI runtime/installer check before publication.

These checks do not certify the visual correctness of a user's annotations. Human review still determines object identity, placement, missing objects, and the accuracy of interpolated boxes. No optical tracking, direction prediction, or cross-camera matching is claimed.
