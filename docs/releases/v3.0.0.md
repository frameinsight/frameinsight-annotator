# Frameinsight 3.0.0

A larger annotation canvas, flexible classes, and desktop updates.

## Annotation workspace

- Right-click a box to change its ID/class, copy to another class, focus or hide its track, remove boxes, or restore a deleted range. Right-click empty canvas for drawing and navigation tools.
- Use the floating canvas tools: **V** selects/moves, **B** draws, **H** pans, and **0** fits the video. Hold **Space** to pan temporarily.
- The redundant filename row and nearby-frame thumbnails are removed. The track list is compact and shortcuts can be opened when needed.
- The larger timeline shows **Present** in the selected class color and **Hidden** in red wherever that track/class has no box. Red, white, and black are excluded from new box-color choices. Existing annotation colors are preserved.

## Classes and identities

- One object ID supports any number of named box classes. Class buttons select what to draw; eye buttons only change what you see.
- Each class has independent boxes, interpolation, and hidden ranges. Copy a class across the whole track, then adjust its copies. Existing destination boxes are preserved.
- Restore accidental deleted ranges between known boxes without drawing every frame again.
- Annotation-only JSON is now schema **3**, with per-class box tracks, presence intervals, exact frame timestamps, provenance, and shared identity IDs. It contains no footage or images. Previous projects remain readable.

## Finish and delivery

- Render the annotated review video, inspect it at **0.5×, 0.25× or 0.125×**, then confirm the intended coverage and run structural validation before JSON export.
- Validation checks references, unique IDs, frame/box coordinates, timestamps, JSON structure, and counts. It cannot identify a visually wrong box or an identity swap; those need human review.
- Installers are provided for Windows x64 and Debian 12+/Ubuntu 24.04+ x64. No developer tools or GPU are needed for manual annotation.
- At startup the app checks for a newer stable release and displays its notes. Choose **Update** or **Skip for now**. Packages are verified before an explicit installation step, and saved projects remain outside the program directory.

## Downloads

- **Window_setup.exe** — Windows installer.
- **frameinsight_3.0.0_amd64.deb** — Debian/Ubuntu desktop package.
- **SHA256SUMS.txt** and **release-manifest.json** — package verification metadata.
- **frameinsight-3.0.0-third-party-sources.tar.gz** — corresponding sources/build recipes for bundled video libraries; annotators do not need to download this.
