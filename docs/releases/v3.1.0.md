# Frameinsight 3.1.0

Organize annotation work by project and continue existing YOLO or MOT work in the editor.

- **Project home:** create a project with named classes, then add multiple videos. Existing projects and annotations remain available. Empty projects remain after deleting their last video.
- **Dark workspace:** playback at the top, canvas tools on the left, and the compact Tracks panel on the right. Shortcuts open as an optional overlay.
- **Consistent class order:** track badges follow project class order and skip missing classes. Selecting another track falls back to an available class when needed; undo/redo preserves the class being edited.
- **YOLO imports:** five-column detection labels or explicitly selected six-column labels with track IDs. Read class lists from obj.names, classes.txt, or dataset YAML; preview frame numbering, counts and ID mappings before applying.
- **MOT 1.1 imports:** load ground-truth gt.txt or a ZIP with gt/gt.txt and optional gt/labels.txt. Choose frame and coordinate bases; ignored rows are excluded, visibility is retained in the evidence note.
- **Safe editing after import:** imports append to existing annotations in one undoable action. ID collisions are remapped, never automatically merged. Missing labels remain Hidden until you explicitly fill or edit with interpolation enabled.
- **Local video paths:** upload a recording or enter the path to a video on the computer running Frameinsight.

Plain YOLO detection files do not contain identities across frames. Each detection becomes a separate track. Use tracked YOLO or MOT to preserve existing tracking. Structural import checks cannot certify visual identity accuracy; inspect playback and use Finish for final review and validation.

Downloads: **Window_setup.exe** for Windows 10/11 x64 and **frameinsight_3.1.0_amd64.deb** for Ubuntu/Debian x86-64. Install over your existing version to keep local projects. Installers are unsigned. Windows packaging is tested in CI; a physical Windows 11 laptop is not part of the test environment.
