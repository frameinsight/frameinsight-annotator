# Frameinsight 3.10.0

Installed copies now update automatically when the app starts. A newer stable release is downloaded and checksum-verified, Frameinsight closes safely, the installer runs, and the updated app reopens. No in-app Update or Install button is required.

- Windows installs updates silently and waits for the old runtime to exit before replacing its files.
- Debian/Ubuntu uses the system authorization prompt and apt. The computer may ask for an administrator password; Frameinsight never receives it. The app reopens after the installed version is verified.
- Startup shows download/install progress. Offline checks and failed downloads release the workspace so you can keep annotating. Failed installation attempts cannot cause a rapid restart loop.
- Projects, videos, annotations and editing history remain in their existing data folders. Source checkouts are not replaced automatically.

**Install 3.10.0 once using your current updater or this release’s installer. Future releases then install automatically on app restart.** Closing a browser tab alone does not stop the app: on Windows choose Exit Frameinsight from its tray icon; on Linux use Close Frameinsight from the application menu. Then open Frameinsight again.

App updates remains available for manual checks and recovery. System authorization or organization security policies may still require normal operating-system interaction.
