# Frameinsight 3.11.0

## Multi-camera annotation

- Choose **Single video** or **Multiple cameras** before adding new annotation work. Opening existing videos keeps the usual editor.
- Create camera sessions from related videos. Show multiple synchronized views, choose the active camera, enlarge a view, and play slowly or step through exact source frames.
- Use **Sync cameras** to align a shared event or enter recording start offsets. Original frames, dimensions and presentation timestamps are preserved; views show **No recording** outside their coverage.
- Create shared people and explicitly link their local tracks across cameras. Select a shared person and draw in another camera to link their new track. Local track numbers stay scoped to each video.
- Keep each camera’s classes, boxes, interpolation and deleted ranges independent. Focus a shared person, inspect per-camera appearance timelines, reassign or unlink tracks, and undo camera/person changes.
- Rename sessions/cameras and add or remove existing recordings through **Manage camera session**. Removing a camera keeps its video and annotations.
- Review the existing live grid, then validate and export a named, compact JSON containing final annotations, source references, timing and shared identities. Images, videos and edit history are excluded.
- Import session JSON with explicit source-to-video matching and source fingerprint checks. Native project backups preserve session associations and their history.

Associations are human-reviewed. This release does not automatically identify people across cameras. Structural validation cannot determine whether a visual identity match is correct. Single-video JSON exports remain unchanged.

See [multi-camera JSON](../multicam-json.md) for the schema and [README](../../README.md#multi-camera-sessions) for the workflow.
