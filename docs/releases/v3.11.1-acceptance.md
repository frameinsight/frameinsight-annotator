# 3.11.1 verification

Local verification passed 290 backend tests, 146 frontend tests, the production build, and all 77 required Chrome browser cases. One optional real-user-video measurement was skipped in isolated test data. Interrupted foreground test runs were resumed successfully against the same isolated database; no user project was used for editing tests.

## Reproduced failures and regression checks

- With four camera previews and a 150 ms delay on each PNG response, the previous player displayed only frames 0 and 23 in secondary cameras. The corrected player visibly displays all 24 source frames before moving on. Frames and annotation overlays remain matched.
- Three browser pages, each displaying four cameras under delayed responses, retain independent positions and valid decoded previews. This is a reproducible load/navigation check, not a claim to have reproduced a teammate's exact operating-system or GPU failure.
- Failed active and passive frame requests recover through Retry frame. Moving away clears stale errors. Returning to a formerly successful frame that now fails also exposes Retry, rather than showing an empty image as loaded.
- Track hiding persists through source stepping, camera switches and reopening the session; saved observations and shared-person assignments remain unchanged.
- Confirmed camera-track deletion preserves other camera annotations and the shared person. Undo restores the removed observations and shared-person link. Unit coverage includes legacy identity UUIDs spanning several videos.
- The decoded-image cache retains at most 32 MiB and eight entries, deduplicates pending loads, evicts safely and retries failures. The displayed image and browser/canvas resources are outside that cache budget.
- Backend concurrency verification reads 128 generated frame requests across four separately indexed cameras and checks exact pixels. A separate real-video probe completed 480 requests with 12 in flight across three recordings, including 2880×1620 footage; all bytes matched their cached PNGs.

Manual Chrome testing confirmed whole-box hiding across frame navigation, camera-specific deletion, Undo, saved identity restoration and synchronized playback to the final frame. Local screenshot: `.frameinsight/qa/multicam-3.11.1.jpg`.
