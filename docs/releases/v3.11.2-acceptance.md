# 3.11.2 verification

Local verification passed the production frontend build, 321 backend tests, 152 frontend tests, and 28 targeted Chrome browser cases covering deletion, project settings, imports, multi-camera editing and validation/export.

## Deletion checks

- Existing class deletion is staged, cancelable and confirmed with affected box/video counts. Browser checks remove a class across two videos, preserve the other class's exact boxes and numeric IDs, reset the selected class, and verify persistence after reload.
- Project deletion requires the current revision and an exact-name UI confirmation. Tests cover empty/populated projects, cancellation, deletion from both library views, neighboring projects, and an editor whose project is deleted in another tab.
- Backend tests cover managed files and all related tables, shared recordings, external files and symlink targets, active imports/exports, native-restore parent jobs, stale revisions, cleanup warnings and normal WebSocket shutdown.
- Class-history tests cover named and legacy geometry, recursive restored history, removal of obsolete class references, Undo of surviving changes, current JSON exports, validation invalidation, and preservation of other-camera assignments.
- Browser recovery tests ensure pending edits block destructive settings changes, deleted selections cannot reappear from stale journals, and a successful server deletion remains successful if browser-storage cleanup fails.

Manual computer-use checks in the in-app browser verified class trash controls, staged changes, confirmation details, typed project-name gating and cancellation against isolated disposable data. Screenshots are saved locally as `.frameinsight/qa/class-delete-3.11.2.jpg` and `.frameinsight/qa/project-delete-3.11.2.jpg`. User projects were not used for editing/deletion tests.

The desktop release workflow gates publication on the full backend/frontend/browser suites and native Windows/Debian install, update/data-preservation and uninstall checks. Physical Windows 10/11 testing is not claimed.
