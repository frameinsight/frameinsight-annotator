# Frameinsight 3.11.2

## Delete existing classes and projects

- Delete an existing class from Project settings or Edit classes using its trash icon. Changes remain staged until Save changes and a second confirmation showing affected boxes and videos.
- Class deletion removes only the selected classes across the project. Other class boxes and surviving track IDs are preserved. Tracks with no remaining classes are removed, and deleted classes cannot return through old range-recovery history.
- Delete empty or populated projects from the projects page or project library. Type the project name to confirm removal of its videos, annotations and camera sessions. External source recordings remain untouched.
- Prevent stale or busy project deletions, clear local recovery records after successful deletion, and handle a project deleted while another tab has it open.
- Run annotation validation again after changing classes. Existing downloaded files are unchanged.

Class and project deletion are permanent; make a project backup first if the work may be needed later. Keep at least one class by adding a replacement before removing the last one.

## Update

Save your work, fully exit Frameinsight through its tray icon, then reopen while online. Closing the browser alone does not stop the app. You can also install the Windows or Debian package over your existing installation; saved projects remain in the app's data directory.
