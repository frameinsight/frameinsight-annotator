# Frameinsight 3.11.3

## Faster corrections, reliable previews and storage controls

- Fix the pause after consecutive box adjustments in large projects (#11). Normal corrections now process the selected track's adjacent keyframe spans, preserve unchanged records, and reuse the frame index. The track list scans annotations once per change, and unchanged box labels avoid unnecessary canvas redraws. Undo, interpolation, review invalidation and durable recovery retain their existing behavior. Legacy deletion gaps use the full validation path when needed.
- Keep the last complete image and matching annotation overlay visible while the next frame loads (#10), in both the editor and multi-camera grid. Swap them together after decoding; editing stays disabled until the requested frame is ready. Failed or delayed frames no longer blank an already loaded preview.
- Show decoded-frame storage per video and clear selected inactive videos from the project library (#9). Source videos, annotations, history and the exact frame ledger are preserved. Reopening verifies the original recording and rebuilds its frames; active workspaces or processing jobs block cache clearing.
- Add a confirmed trash action to every person in **People across cameras**, including unlinked entries (#8). Removing a shared person unlinks its camera tracks without deleting local IDs or annotations. Session Undo restores the person and links.

- Prevent a delayed new-track save in the multi-camera workspace from cancelling the first box while it is being drawn.

## Update

Save your work, fully exit Frameinsight through the tray icon, then reopen while online. Closing the browser alone does not stop the app. You can also install the Windows or Debian package over the existing installation; saved projects stay in the app's data directory.
