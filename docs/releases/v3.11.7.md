# Frameinsight 3.11.7

## Camera session management

- Delete obsolete camera sessions from the project library (#15). Confirm the session name and scope before deletion. Source videos, local tracks and boxes, other camera sessions and downloaded exports are kept. The session itself cannot be restored with Undo.
- Reimport corrected multi-camera JSON without duplicate tracks (#16). Add remains the default; choose Replace annotations on mapped cameras to update existing annotations. Preview current/imported track and box counts for each camera, then explicitly confirm.
- Warn when other sessions use mapped videos. Those sessions remain, but assignments to replaced local tracks are removed and need relinking. The imported shared people, camera timing and assignments are restored in a new session.
- Bind replacement confirmation to the current project and affected sessions. Changed annotations or session links require a fresh preview. Failed imports roll back the entire replacement, including session associations. Unmapped videos and their annotations remain intact.

Keep a native project backup before replacement if you may need the old work. Imports are not added to the client Undo stack.

## Update

Save, fully exit Frameinsight through its tray icon, then reopen while online for the startup update. Closing only the browser does not stop the app. Alternatively, install the Windows or Debian package over the current installation. Confirm **LOCAL · 3.11.7**.
