# Version 3.2.1 verification

Release checks use synthetic videos and isolated annotation databases. User recordings, annotations, cached images and generated exports are excluded from Git and installer payloads.

The live project's project, video, entity, operation and frame records had identical content hashes before and after both the 3.2.0 and 3.2.1 service restarts; a SQLite backup was created first.

The 3.2.0 candidate passed the local suite and both installed-package checks, but its CI browser run exposed a closed-menu shortcut race. It was not published. Version 3.2.1 includes the fix and a regression test for the closing-menu state.

The 3.2.1 production build and 98 frontend tests passed locally. Four focused Chrome regressions passed, including a held closing-menu animation with real keyboard focus and immediate Delete/H/V actions. The release pipeline runs the complete suite on the tagged commit.

The release checks cover:

- Backend domain, project/class renaming, recovery history, structural validation, immutable export proof, imports, update handling and packaging rules.
- Frontend geometry, interpolation, class settings, label layout and store behavior.
- Chrome acceptance for multi-class tracks, copy/resize/interpolation, hidden ranges and recovery, undo/redo, save/reload, imports, project settings, final validation/export and update handling.
- Compact layouts at 1440 pixels and 1366 × 768, class visibility capsules, timeline controls and icon-only canvas tools.
- Selected resize handles remaining usable when another class badge overlaps them; right-clicking a badge still targets that badge's track and class.
- Manual computer-use inspection of the compact workspace, label context menu, dark dropdowns, review in the existing canvas, and successful full-page validation/export.

The release pipeline repeats the automated suite on the tagged commit. Before publication it also builds and exercises the Windows installer on a native Windows CI runner and the Debian package in a disposable container. Installed-runtime checks verify structural validation and media-free JSON without a rendered review, stale export rejection after settings changes, legacy rendering compatibility, restart persistence, and data preservation through upgrade/removal. Machine-readable reports are attached to the release assets.

The optional real-clip navigation measurement is skipped in isolated environments without that private recording. The production build emits Vite's existing non-blocking bundle-size advisory.

Manual UI checks use Linux browser environments. Windows CI does not substitute for testing SmartScreen, antivirus or performance on a physical Windows 11 annotator laptop. Structural validation cannot certify object identity or visual placement; the annotator reviews those in the canvas.
