# Frameinsight 3.2.1

A more compact annotation workspace, editable project settings, and a simpler path from visual review to validated JSON.

- **Consistent dark components:** the shadcn Maia/Olive preset, capsule buttons, readable dark dropdowns, and smaller controls throughout the app.
- **More room for video:** project videos appear in a searchable table with status and dates. Playback, frame navigation and import share the timeline row; canvas tools live above the picture.
- **Clearer editing tools:** dedicated icons for copying boxes and deleting/restoring ranges, with hover descriptions and shortcuts. Right-click either a box or its class/ID badge to open the same menu. Labels stay readable when boxes overlap.
- **Editable names:** rename projects and classes at any time, including before export. Names update together across the project's videos, current annotations and saved history, while track IDs and geometry stay intact.
- **Simpler class copying:** choose a source and target class, see the selected track and frame count, and copy across that track. Existing target boxes are kept.
- **Review without waiting for a render:** Finish prompts you to review the existing canvas at normal or slow speeds. Continue to a full-page Validate & export screen when you are ready.
- **Structural validation:** checks identities, references, rectangle data, source frames, JSON and export consistency. Boxes may extend outside the image; project-specific placement and identity accuracy remain part of human review. Saved edits or renamed classes require fresh validation before export.
- **Reliable shortcuts after closing menus:** Escape dismisses the menu immediately for annotation shortcuts, even while its closing animation finishes. Delete, undo and canvas tools are no longer blocked by a closed menu.
- **Editing fixes:** restore accidentally deleted ranges, retain the selected class through editing, use all canvas space after removing the left tool rail, activate focused controls without accidentally advancing playback, and resize the selected box even when another label overlaps its handle.

Interpolation and background dimming are always enabled. Hiding tracks or classes changes only the display; annotations stay saved and exported.

Downloads: **Window_setup.exe** for Windows 10/11 x64 and **frameinsight_3.2.1_amd64.deb** for Ubuntu 24.04+/Debian 12+ x86-64. Install over your existing version to keep local projects. Installers are unsigned. The release pipeline tests the Windows installer on a Windows CI runner and the Debian package in a disposable container; it does not claim testing on a physical Windows 11 laptop.
