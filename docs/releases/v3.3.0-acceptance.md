# Frameinsight 3.3.0 acceptance

This release adds display-only track colors, anchor-frame navigation, single-video native JSON import, clearer editing/recovery guidance and batched frame indexing.

Local validation includes 179 backend tests, 100 frontend unit tests, production frontend build, 44 passing Chrome acceptance tests (one optional private-clip benchmark skipped), and manual inspection in the in-app browser using isolated synthetic footage. Native JSON tests compare export/import/export geometry, numeric IDs, classes, colors and provenance; verify deleted intervals, collisions and wrong-video rejection; and undo the import. The browser exercises the actual exported-file upload, preview and application flow.

Indexing comparison on the 24-frame numbered fixture: old 0.303 seconds, batched 0.213 seconds in one local run. PNG checksums and exact timestamp ledger rows match. This is a small synthetic check, not a promise about long videos or an older laptop. A 65-frame test covers full batches and final remainder with exact pixel checks.

The release workflow reruns all suites and builds/tests the Windows installer on a Windows runner and the Debian package inside a headless container. Its publish job requires every build/test job to succeed. The installed-runtime checks include native JSON import preview and collision mapping. Neither physical Windows 10/11 hardware nor a native Linux desktop installer GUI was tested.

Optional private real-video benchmark requires its separately configured local clip and is skipped when unavailable. CVAT Video 1.1 XML UI import remains deferred; YOLO and MOT imports remain supported. The team did not supply the deletion screenshot or reproducible previous-frame-copy failure; existing deletion/copy regressions are checked and empty projects are labeled explicitly.
