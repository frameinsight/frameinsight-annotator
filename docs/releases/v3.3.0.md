# Frameinsight 3.3.0

Annotation workflow improvements from team feedback:

- Switch between class colors (default) and stable track display colors to separate overlapping objects. Saved annotation colors remain unchanged.
- Find anchor frames using timeline diamonds and previous/next keyframe controls or [ / ].
- Import a single-video Frameinsight annotation JSON (v2/v3) onto the matching video. Preview IDs/counts first; existing tracks stay, colliding IDs are remapped, and the whole import is undoable. Boxes, class styles, keyframe provenance and deleted ranges are preserved. Old validation proofs and undo history are not imported; use project backups for full recovery.
- Find joining through the Tracks heading, with clearer box replacement and class-copy guidance.
- See explicit empty-project messaging after removing a project's last video.
- Video preparation hashes while copying and batches frame-ledger writes, preserving exact images and source timestamps. Preparation progress appears while indexing.

Download Window_setup.exe for Windows 10/11 x64, or the .deb package for Debian/Ubuntu. Existing projects stay in the app's data directory. The installers remain unsigned. Windows validation runs on a Windows CI runner; Debian validation runs in a headless container, not physical desktop hardware.
