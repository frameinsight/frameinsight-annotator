# Frameinsight 3.4.1

- Wider frame-number input keeps long frame numbers readable.
- New tracks receive an unused color immediately. Drawing their first box opens ID/class registration automatically.
- Removed track joining and merging from the interface. Changing an ID to one already used by another track is rejected; existing annotations are preserved.
- Removed the tracks-panel toggle and replaced the selected-track/color/history toolbar controls with compact keyboard hints.
- ID/class editing, undo/redo, and View by class / View by track remain available in the canvas right-click menu.

For multiple classes on the same object, select its existing track and choose another class in the class bar.

Download Window_setup.exe for Windows 10/11 x64, or the .deb package for Debian/Ubuntu. Existing projects stay in the app's data directory. Windows installer/runtime validation runs on a native Windows CI runner; Debian validation runs in a headless container. Installers remain unsigned.
