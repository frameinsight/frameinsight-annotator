# Frameinsight 3.4.2

Fixes track IDs continuing across videos in the same project.

- Each new video can start at Track 1.
- ID editing rejects duplicates only where tracks share a video.
- JSON, YOLO and MOT imports check number collisions in the destination video.
- Export validation accepts the same number in separate videos; export metadata explains that video_id and track_id together identify a video track.
- Existing annotations, internal identity UUIDs, saved numbers and undo history are preserved. No automatic renumbering is performed.

If a track in your second video was already assigned 4, select it, press I, enter 1 and save. ID 1 must be unused in that video.

Install the update over your existing installation. Project data stays in the app data directory. Installers remain unsigned; Windows acceptance runs on native CI and Debian acceptance runs in a headless container.
