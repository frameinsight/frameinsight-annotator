# 3.5.0 verification

Local Ubuntu verification before tagging:

- 184 backend tests passed.
- 106 frontend unit tests passed.
- All 50 applicable Chrome browser tests passed in one full run. One optional private-video performance benchmark was skipped.
- Production frontend build, release version consistency and diff whitespace checks passed. Dependency versions are unchanged.
- New browser regressions cover all four label modes, preference persistence, optional registration and manual I access, source-pixel dimensions at different zoom levels, consistent class colors in labels/pills/sidebar/timeline, selection of coincident boxes, and editing through another class's displaced label.
- The nested-box reproduction failed on the previous build and passes with this fix. The existing badge/context-menu regression now accounts for the overlap chooser only where boxes overlap.
- Display preference changes are checked against saved annotation state; moving/resizing and undo are checked independently. The full suite also exercises interpolation, range recovery, video-scoped IDs, imports, export validation and updater behavior.
- Inspected Canvas settings, compact labels, class colors and persistent dimensions through computer use. Selected an overlapping box from its menu, moved it, and undid the test adjustment.
- Tests used an isolated data directory. Existing local projects, videos, annotations, operation history and frame ledgers were backed up and verified unchanged after restarting the local app at 3.5.0.

The tagged release workflow repeats the full suite and gates publication on native Windows installer/runtime verification, Debian installed-runtime verification and source-license packaging. Successful releases include machine-readable verification reports alongside the installers.

Windows validation uses a native CI runner; Debian validation uses a headless container. This is not a physical Windows 11 laptop acceptance test.
