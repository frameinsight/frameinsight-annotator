# Frameinsight 3.5.0

Addresses all five canvas feedback issues (#1–#5).

- **Labels:** choose All labels, Selected box only, Compact IDs only, or Hide labels. Outlines and editing still work in every mode.
- **Dimensions:** see width × height in source pixels while drawing, moving or resizing. Optionally keep the selected box’s dimensions visible; zoom never changes these measurements.
- **New tracks:** first-box ID confirmation remains on by default. Turn it off to accept automatic IDs, class and track colors, then press I to edit whenever needed.
- **Class colors:** View by class now consistently uses the project palette across tracks, box labels, sidebar dots and the timeline. View by track keeps one color for each track across its classes.
- **Overlapping boxes:** the selected class stays editable when another class’s label covers it. Right-click an overlap and choose Select overlapping box to select an exact track and class, including identical boxes.

Open Canvas settings beside the zoom tools or from the right-click menu. Preferences stay in your browser; existing annotations, IDs, class styles and exports are not rewritten. The per-video track ID fix from 3.4.2 is included.

Install over your existing installation. Project data stays in the app data directory. Installers remain unsigned; Windows acceptance runs on native CI and Debian acceptance runs in a headless container.
