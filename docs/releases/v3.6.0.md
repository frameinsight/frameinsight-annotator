# Frameinsight 3.6.0

Refill deleted sections without redrawing every frame.

- **Two replacement boxes:** after deleting a range, keep the same track and class selected and draw on two frames inside it. Only the frames between those new boxes fill automatically. Either drawing order works, including after saving and reopening the project.
- **Interpolate between frames:** press **Shift+K** or right-click a box or its label. Enter two frame numbers that already have boxes, check the preview, and choose **Interpolate frames**. This works with ranges deleted in older versions too.
- **Keep your corrections:** existing boxes inside the chosen range, other classes and hidden frames outside it are preserved. Adjust any generated box normally. **Ctrl+Z** undoes the entire fill.
- **Repeated deletions:** overlapping deleted ranges now consistently use the latest deletion. Old replacement boxes do not accidentally refill a newer gap.

Example: delete frames 1000–1100, then draw new boxes on 1020 and 1080. Frames 1021–1079 fill; 1000–1019 and 1081–1100 stay Hidden. If you already drew those two boxes, use **Shift+K** with 1020 and 1080.

Interpolation estimates positions between your boxes; inspect movement and add corrections when needed. **K** retains its existing behavior of filling ordinary gaps while respecting explicit deletions.

Install over your existing installation. Project data stays in the app data directory. Installers remain unsigned; Windows acceptance runs on native CI and Debian acceptance runs in a headless container.
