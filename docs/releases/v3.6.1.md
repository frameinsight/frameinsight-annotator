# Frameinsight 3.6.1

Fixes automatic interpolation in existing projects that contain overlapping deletions saved by older versions. These leftover deletion markers could still block filling after two replacement boxes were drawn in 3.6.0.

- Keep the same track and class selected, then draw two boxes inside the deleted section. Intermediate frames fill automatically.
- If you already drew the replacement boxes in 3.6.0, move or resize either boundary box to trigger the fill after updating. No interpolation-button click is needed.
- Frames outside the two boxes, other classes and other tracks stay unchanged. Later deletions are still respected. **Ctrl+Z** reverses the edit and its fill together.
- Original deleted-box recovery remains available; normalizing old deletion markers does not discard the recovery history.

The optional **Shift+K** command remains available when you want to specify a range explicitly.

Install over your current version, then reopen the app. Your local project data is preserved. Windows acceptance runs on native CI; Debian acceptance runs in a headless container.
