# Frameinsight 3.7.0

Prepare shorter videos before annotation and give JSON downloads meaningful names.

- **Trim sections** lives on the project/video homepage. Choose a source, drag start/end handles, and add the sections you want to keep. A large preview follows the source frame under the handle.
- **Create new video** joins kept sections in source order into a separate MP4. Preview it, save it, and upload it using **New video**. Frame numbers start again at 0.
- Original dimensions, pixel aspect ratio and selected-frame timing are retained; there is no image cropping, resizing or padding. Audio from the first audio track is kept when present. H.264/AAC encoding changes compression/file size. Odd dimensions use 4:4:4 video and may need a compatible player for preview.
- Existing videos and annotations stay unchanged. There are no crop/scope controls in the annotation workspace.
- **JSON filename** defaults to the video name and can be edited before downloading. The app checks stale/missing exports before download. Browser-managed download restrictions still apply.
- Includes 3.6.1’s automatic interpolation repair for overlapping deletions from older versions.

Install over the current version and reopen the app. Existing projects remain intact. Windows acceptance runs on a native CI runner; Debian acceptance runs in a headless container.
