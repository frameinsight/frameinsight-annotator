# Frameinsight 3.8.1

Trim sections now works like a simple video editor.

- Play the original video and press **C** to place cuts without stopping playback. Seek with the playhead or step frame by frame for precise boundaries. Each cut starts a new section at the current frame.
- Select a section on the timeline or list, then press **Delete** to remove it. Removed sections stay visible in red and can be restored.
- **Ctrl+Z** undoes cuts/removals; **Ctrl+Shift+Z** redoes them. Typing in fields never places cuts or deletes sections.
- **Space** plays/pauses. Choose 0.25×, 0.5×, 1× or 2× speed. Browser-incompatible source formats can create a playback preview without altering their cuts.
- **Combine & save video** joins kept sections into a separate MP4. Original dimensions, aspect ratio, selected frame timing and audio remain preserved as in 3.7.0.
- Existing saved 3.7.0 section selections and prepared downloads reopen in the new interface. Original videos, projects and annotations remain unchanged.

Install over your current version and reopen the app. Includes 3.7.0’s named JSON downloads and previous interpolation repairs.
