# 3.9.0 verification

Local checks cover the production frontend build, 120 frontend tests, 210 backend tests, all four project/import browser scenarios and all six updater browser scenarios.

- Replacement coverage: original ID preservation, existing-state removal, shared identities in another video, other-video observations and review records, interval/link recovery, invalid JSON rejection, stale-revision rejection, Add-mode collision mapping, save retries, reload and one-action Undo/Redo.
- Manual browser check on isolated test data: preview two existing tracks versus one imported track, require explicit confirmation, replace while retaining ID 7, and Undo restores tracks 7 and 9.
- Debian handoff tests: private source remains private, staged copy is checksum-verified and readable by package-manager users, the frozen helper executes a system shell before launching the installer, and installer stdout/stderr and nonzero exits are recorded.
- The installed-package acceptance test invokes the real frozen helper and performs a real apt reinstall in a disposable Debian container. It verifies the running-app guard is clear, an unprivileged package-manager user can read the staged installer, and saved database bytes survive. GUI authorization is substituted with a test adapter; physical Ubuntu desktop/polkit interaction is not claimed.

Publication is gated on the full browser/backend/frontend suites plus native Windows and Debian install/runtime/upgrade/data-preservation checks. Corresponding sources and platform verification reports accompany the release. Older Linux versions with a broken updater may need one manual installation to obtain this fix.
