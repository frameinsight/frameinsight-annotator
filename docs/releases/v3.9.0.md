# Frameinsight 3.9.0

## Review revised annotation JSON without duplicate tracks

**Import annotations → Frameinsight annotations — JSON** now offers:

- **Add to existing annotations:** keep current work and add imported tracks. Colliding IDs receive new numbers as before.
- **Replace this video’s annotations:** validate the file, preview how many tracks and boxes will be replaced, then confirm. Imported numeric IDs are preserved and other videos stay unchanged. **Ctrl+Z** restores the previous annotations; **Ctrl+Shift+Z** reapplies the replacement, including after reopening the app.

Invalid files and stale previews cannot replace saved work. A failed save can be retried without applying the import twice. Review and validate the imported annotations again before exporting.

## Debian update installation

The verified public installer is staged in a location the system package manager can read, while annotation folders remain private. The frozen app and helper leave the runtime before installation starts. Installer output and exit codes are retained in `install-handoff.log`; nonzero exits show troubleshooting details and the verified package path.

**If your older Linux version cannot update itself:** close Frameinsight using its application-menu close action, download this release’s `.deb`, and install it manually once. Saved projects remain in place. Updates launched from this version use the repaired handoff. Closing the browser tab alone does not stop the app.

Windows users can install `Window_setup.exe` over their current version. Both installers include the JSON replacement feature. Reopen the app and confirm **LOCAL · 3.9.0**.
