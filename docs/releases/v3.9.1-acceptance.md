# 3.9.1 verification

Local verification: production frontend build, all 120 frontend tests and all five Chrome canvas-feedback scenarios passed.

The dimension regression covers drawing, mouse release, moving, resizing, zoom invariance, Undo, reload, selecting another box without moving it, changing frames, hiding a class/track and restoring visibility. It also loads a legacy browser preference with `keepDimensions: false`; the readout stays visible automatically, while unrelated preferences remain available.

Manual computer use on an isolated fixture confirms that selecting Track 1 without dragging shows **100 × 200 source px** at the bottom right of the canvas. Selection and visibility checks do not change saved annotations.

Publication requires the complete frontend/backend/browser checks and native Windows/Debian installed-runtime, update and data-preservation tests. The release includes their verification reports. Physical Windows/Ubuntu desktop installer interaction is not claimed.
