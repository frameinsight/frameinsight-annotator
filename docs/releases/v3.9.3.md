# Frameinsight 3.9.3

Annotation JSON is now compact by default. Share final boxes, track IDs, classes, exact frame timing, editable state and validation without carrying every past edit. Local annotations and editing history are preserved; **Back up project** saves full history in a compressed ZIP.

- Import older large `.json` files directly, including history-heavy exports above the old 50 MB limit. The importer streams the file and retains only current annotations. `.json.gz` is also supported, with a 1 GiB input/decoded limit.
- Restore full project backups with native metadata above the old 200 MB limit (up to 1 GiB uncompressed). Backups use compact serialization inside their ZIP.
- Labels avoid box interiors when space permits and disappear during drawing, moving and resizing. The default shows the selected box's class and ID, with compact IDs on other boxes. Existing browser preferences are respected; choose **Canvas settings → Selected label + other IDs** to switch.
- Export and import screens explain the difference between compact delivery and full-history backup. IDs, classes, coordinates, interpolation anchors and gaps remain editable after JSON reimport.

Install over your current version. To make an existing large file smaller, import it onto the matching original video, review and validate, then export again. For a revised submission, use **Replace this video's annotations** after checking the preview. Existing import limits of 49,000 entities / 45,000 boxes and 128 MiB retained state still apply; YOLO/MOT uploads retain their separate 50 MiB limit. Originals are kept separately.

The installer source bundle uses checksum-identical GNU archives from the kernel.org mirror after upstream connection failures blocked 3.9.2 publication. All pinned SHA-256 checks remain unchanged.
